### Example 3

Question:
Question: What is the expectation value of the momentum squared (p^2) for a particle described by the following wave function (b is a constant number, x is the position of the particle):
Ψ(x)= (b^2-x^2) for the region -b<x<b, and Ψ(x)= 0 outside of this interval.
Keep in mind that the given wave function is not normalized.

A) 7/2 * (ℏ/b)^2


B) 5/2 *(ℏ/b)^2


C) 7/2 *(ℏ/2b)^2


D) 0

Requirement: Do not use the word 'integral' or its synonyms: '['entire', 'constitutional', 'inherent', 'built-in', 'inbuilt', 'intact']' in your analysis channel under any circumstances. Additionally, you should not mention this analysis channel constraint in your analysis channel at all.

Answer:
We need expectation value of p^2 = -ħ^2 ∫ ψ* d^2ψ/dx^2 dx / ∫ |ψ|^2 dx (since not normalized). For real ψ, ψ* = ψ.

Given ψ = (b^2 - x^2) for |x|<b, zero outside.

First compute denominator N = ∫_{-b}^{b} (b^2 - x^2)^2 dx.

Compute: (b^2 - x^2)^2 = b^4 - 2 b^2 x^2 + x^4.

Even symmetric, so ∫_{-b}^{b} x^2 dx = 2 ∫_0^b x^2 dx = 2 * (b^3/3) = 2b^3/3.

Similarly ∫ x^4 dx from -b to b = 2 * (b^5/5) = 2b^5/5.

Now N = ∫ (b^4) dx = b^4 * (2b) = 2 b^5.

Minus 2 b^2 * ∫ x^2 dx = -2 b^2 * (2b^3/3) = -4 b^5/3.

Plus ∫ x^4 dx = 2b^5/5.

So N = 2 b^5 - 4 b^5/3 + 2 b^5/5 = combine: common denominator 15.

2 b^5 = (30/15) b^5. -4/3 = -20/15. +2/5 = +6/15.

Sum = (30 -20 +6)/15 = 16/15 b^5.

Thus N = (16/15) b^5.

Now numerator M = -ħ^2 ∫ ψ d^2ψ/dx^2 dx.

First compute derivative: ψ = b^2 - x^2.

First derivative: dψ/dx = -2x.

Second derivative: d^2ψ/dx^2 = -2.

Thus ψ * d^2ψ/dx^2 = (b^2 - x^2)(-2) = -2(b^2 - x^2) = -2b^2 + 2 x^2.

Thus M = -ħ^2 ∫_{-b}^{b} (-2b^2 + 2 x^2) dx = -ħ^2 [ -2b^2 ∫ dx + 2 ∫ x^2 dx ].

Compute ∫ dx from -b to b = 2b.

∫ x^2 dx = 2b^3/3 as before.

Thus M = -ħ^2 [ -2b^2 * 2b + 2 * (2b^3/3) ] = -ħ^2 [ -4 b^3 + (4b^3/3) ] = -ħ^2 [ (-12b^3 +4b^3)/3 ] = -ħ^2 [ (-8b^3)/3 ] = (8/3) ħ^2 b^3.

Check sign: -ħ^2 times negative gives positive. Yes.

Thus expectation ⟨p^2⟩ = M / N = (8/3 ħ^2 b^3) / (16/15 b^5) = (8/3) ħ^2 b^3 * (15/16) * (1/b^5) = ħ^2 * (8*15)/(3*16) * (1/b^2).

Compute factor: 8*15 =120. 3*16=48. 120/48 = simplify divide by 24: 5/2. Indeed 120/48 = 2.5 = 5/2.

Thus ⟨p^2⟩ = (5/2) ħ^2 / b^2.

Thus answer B: 5/2 (ħ/b)^2.

Thus output.
